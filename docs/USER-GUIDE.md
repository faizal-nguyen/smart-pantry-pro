# Guide Utilisateur - Smart Pantry Pro 🥘

## Bienvenue dans Smart Pantry Pro !

Smart Pantry Pro est votre assistant personnel pour une cuisine organisée, intelligente et sans gaspillage. Ce guide vous accompagne dans la découverte de toutes les fonctionnalités de l'application.

**🎉 Nouveau dans la version 2.0 :** Assistant nutritionnel IA, planification intelligente des repas, communauté sociale, intégration IoT, analyses prédictives, et architecture offline-first avancée!

## 📱 Premiers Pas

### Installation
1. **Sur mobile** : Ajoutez l'application à votre écran d'accueil via votre navigateur
2. **Sur ordinateur** : Utilisez l'application directement dans votre navigateur
3. **Mode hors-ligne** : L'application fonctionne même sans connexion internet

### Création de compte
1. Cliquez sur "S'inscrire" sur la page d'accueil
2. Entrez votre email et créez un mot de passe sécurisé
3. Confirmez votre email (vérifiez vos spams)
4. Complétez votre profil avec vos préférences alimentaires

### Configuration initiale
1. **Paramètres de confidentialité** : Choisissez vos préférences de partage de données
2. **Allergies et restrictions** : Renseignez vos restrictions alimentaires
3. **Préférences culinaires** : Sélectionnez vos cuisines préférées
4. **Autorisations** : Acceptez l'accès à la caméra et au microphone
5. **🆕 Profil santé** : Complétez votre profil nutritionnel (optionnel)

## 🏠 Gestion de votre Inventaire

### Vue d'ensemble
L'inventaire est le cœur de Smart Pantry Pro. Il vous permet de suivre tous vos produits alimentaires en temps réel.

### Ajouter des produits

#### 📱 Smart Scanner (Recommandé)
1. Appuyez sur le bouton "Scanner" en bas de l'écran
2. Choisissez votre mode :
   - **Produit unique** : Pour scanner un seul article
   - **Multi-produits** : Détection de plusieurs articles simultanément
   - **Réseaux sociaux** : Extraire des recettes depuis Instagram/TikTok

**Mode Multi-produits** :
1. Placez plusieurs produits devant la caméra
2. Attendez la détection automatique (zones colorées)
3. Vérifiez les produits détectés
4. Ajustez les quantités si nécessaire
5. Confirmez l'ajout

**Conseils pour un scan optimal** :
- Éclairage naturel de préférence
- Étiquettes bien visibles
- Évitez les reflets sur les emballages
- Stabilisez votre appareil

#### 🗣️ Commandes Vocales
1. Appuyez sur l'icône microphone
2. Dites votre commande : "Ajoute 2 litres de lait"
3. Confirmez l'ajout

**Exemples de commandes vocales** :
- "Ajoute 500 grammes de tomates"
- "Met 3 pommes dans le frigo"
- "Enlève une bouteille d'eau"
- "Combien j'ai de pâtes ?"
- "🆕 Qu'est-ce qui expire bientôt ?"
- "🆕 Suggère-moi un repas sain"

#### ✏️ Ajout Manuel
1. Cliquez sur "+" dans l'inventaire
2. Saisissez le nom du produit
3. Renseignez la quantité et l'unité
4. Ajoutez la date de péremption
5. Choisissez l'emplacement de stockage

### Organisation de l'inventaire

#### Catégories automatiques
Les produits sont automatiquement classés par :
- **Frais** : Fruits, légumes, produits laitiers
- **Sec** : Pâtes, riz, conserves
- **Surgelé** : Produits congelés
- **Boissons** : Eaux, jus, alcools

#### Emplacements
Organisez par zones de stockage :
- **Réfrigérateur** : Température 0-4°C
- **Congélateur** : Température < -18°C
- **Placard** : Température ambiante
- **Cave** : Pour les vins et conserves
- **🆕 Appareils IoT** : Synchronisation automatique

#### Alertes de péremption

**Système de couleurs** :
- 🟢 **Vert** : Plus de 7 jours restants
- 🟡 **Jaune** : 3-7 jours restants (à utiliser bientôt)
- 🔴 **Rouge** : 1-2 jours restants (urgent)
- ⚫ **Noir** : Expiré (à jeter)

**Notifications** :
- **7 jours avant** : Notification douce
- **3 jours avant** : Alerte avec suggestions d'utilisation
- **1 jour avant** : Alerte critique
- **Jour d'expiration** : Rappel final
- **🆕 Prédictions IA** : Alertes anticipées basées sur vos habitudes

- Assurez-vous qu'ils sont sur le même réseau
- Redémarrez l'appareil IoT
