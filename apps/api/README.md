# Smart Pantry API

API backend pour l'application Smart Pantry Pro.

## 🚀 Démarrage rapide

```bash
./start.sh
```

Le serveur démarrera sur http://localhost:3030

## 📋 Prérequis

- Node.js v22+
- Fichier `.env` configuré

## ⚙️ Configuration

Le fichier `.env` doit contenir:

```bash
PORT=3030
SUPABASE_URL=https://jwoxacnflphclslpqfzs.supabase.co
SUPABASE_ANON_KEY=votre_clé
SUPABASE_SERVICE_KEY=votre_clé
```

## 📡 Endpoints

- `GET /` - Info API
- `GET /api/health` - Health check
