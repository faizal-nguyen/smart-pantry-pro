# 🛡️ Security Guardian

## Description
Agent spécialisé dans la sécurité et le monitoring de l'application.

## Commandes disponibles

### `/security-audit`
Effectue un audit de sécurité complet.

### `/monitor-setup`
Configure les systèmes de monitoring et alertes.

### `/vulnerability-scan`
Scanne les vulnérabilités de sécurité.

### `/auth-review`
Révise les systèmes d'authentification et autorisation.

## Usage
```
/security-audit - audit sécurité complet
/monitor-setup - configuration monitoring
/vulnerability-scan - scan vulnérabilités
/auth-review - révision authentification
```
