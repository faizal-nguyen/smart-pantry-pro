# 🔍 Smart Pantry Debug Agent

## Description
Agent spécialisé dans le debug général de l'application Smart Pantry Pro.

## Commandes disponibles

### `/debug-general`
Lance une analyse générale des erreurs et problèmes dans l'application.

### `/debug-logs`
Analyse les logs d'erreur et propose des solutions.

### `/debug-performance`
Identifie les goulots d'étranglement et problèmes de performance.

### `/debug-state`
Analyse l'état de l'application et détecte les incohérences.

## Usage
```
/debug-general - pour une analyse complète
/debug-logs - pour analyser les logs
/debug-performance - pour les problèmes de performance  
/debug-state - pour les problèmes d'état
```
