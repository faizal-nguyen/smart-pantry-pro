# Available Commands Index

## 🛡️ Cypher Debug System Commands

### Orchestrators
- **`debug-orchestrator`**: Master debugging orchestrator for complex issues
- **`tech-lead-orchestrator`**: Technical lead for planning and architecture
- **`project-analyst`**: Analyzes project structure and technology stack
- **`team-configurator`**: Configures agent routing rules

### Core Development
- **`code-archaeologist`**: Deep code exploration and understanding
- **`code-reviewer`**: Automated code review and quality checks
- **`documentation-specialist`**: Documentation generation and maintenance
- **`performance-optimizer`**: Performance analysis and optimization

### Frontend Development
- **`frontend-developer`**: General frontend development tasks
- **`react-component-architect`**: React component design and architecture
- **`react-nextjs-expert`**: Next.js specific development
- **`tailwind-css-expert`**: Tailwind CSS styling and optimization

### Backend Development
- **`backend-developer`**: General backend development tasks
- **`api-architect`**: API design and implementation
- **`django-api-developer`**: Django REST API development
- **`django-backend-expert`**: Django backend expertise
- **`django-orm-expert`**: Django ORM optimization

### Framework Specialists
- **`laravel-backend-expert`**: Laravel backend development
- **`laravel-eloquent-expert`**: Laravel Eloquent ORM
- **`rails-api-developer`**: Rails API development
- **`rails-backend-expert`**: Rails backend expertise
- **`rails-activerecord-expert`**: Rails ActiveRecord ORM
- **`vue-component-architect`**: Vue.js component architecture
- **`vue-nuxt-expert`**: Nuxt.js development
- **`vue-state-manager`**: Vue state management

## 🚀 Smart Pantry Pro Specific Commands

### Feature Agents
- **`cipher-generate-feature`**: Generate new features with Cipher framework
- **`inventory-camera-agent`**: Camera-based inventory management
- **`voice-ai-agent`**: Voice AI interactions

### System Agents
- **`cipher-executor-agent`**: Execute Cipher framework tasks
- **`cipher-validator-agent`**: Validate Cipher implementations
- **`debug-agent`**: General debugging utilities
- **`performance-agent`**: Performance monitoring
- **`security-agent`**: Security analysis and hardening

## Usage Examples

### Debugging Complex Issues
```bash
# Use the debug orchestrator for systematic debugging
claude use debug-orchestrator "Users report recipe ingredients not saving"
```

### Implementing New Features
```bash
# Use tech lead for planning
claude use tech-lead-orchestrator "Plan meal planning feature"

# Generate feature with Cipher
claude use cipher-generate-feature "Create meal planning module"
```

### Code Review
```bash
# Review recent changes
claude use code-reviewer "Review the recipe management changes"
```

### Performance Optimization
```bash
# Analyze performance issues
claude use performance-optimizer "Recipe search is slow"
```
