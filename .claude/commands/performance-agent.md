# ⚡ Performance Optimizer

## Description
Agent spécialisé dans l'optimisation des performances mobiles et web.

## Commandes disponibles

### `/perf-analyze`
Analyse les performances de l'application.

### `/mobile-optimize`
Optimise spécifiquement pour les appareils mobiles.

### `/bundle-optimize`
Optimise la taille des bundles et le chargement.

### `/memory-analyze`
Analyse l'utilisation mémoire et détecte les fuites.

## Usage
```
/perf-analyze - analyse performances globales
/mobile-optimize - optimisation mobile
/bundle-optimize - optimisation bundles
/memory-analyze - analyse mémoire
```
