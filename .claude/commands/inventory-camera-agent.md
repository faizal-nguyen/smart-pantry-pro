# 📷 Inventory & Camera Expert

## Description
Agent spécialisé dans le scanner de codes-barres, caméra et gestion d'inventaire.

## Commandes disponibles

### `/camera-setup`
Configure les services caméra et scanner.

### `/barcode-debug`
Debug les problèmes de scan de codes-barres.

### `/inventory-sync`
Synchronise et optimise la gestion d'inventaire.

### `/camera-permissions`
Gère les permissions caméra et accès aux médias.

## Usage
```
/camera-setup - configuration caméra/scanner
/barcode-debug - debug scan codes-barres
/inventory-sync - synchronisation inventaire
/camera-permissions - gestion permissions caméra
```
