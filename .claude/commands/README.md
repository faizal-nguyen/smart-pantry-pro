## Comment utiliser
1. Référez-vous au fichier de l'agent correspondant à votre besoin
2. Utilisez la commande appropriée (ex: `/debug-general`, `/voice-setup`)
3. L'agent spécialisé sera automatiquement invoqué pour traiter votre demande
