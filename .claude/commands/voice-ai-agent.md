# 🎤 Voice & AI Specialist

## Description
Agent spécialisé dans la reconnaissance vocale et l'IA conversationnelle.

## Commandes disponibles

### `/voice-setup`
Configure et initialise les services de reconnaissance vocale.

### `/voice-debug`
Debug les problèmes de reconnaissance vocale.

### `/ai-optimize`
Optimise les interactions IA et les réponses conversationnelles.

### `/voice-permissions`
Gère les permissions microphone et audio.

## Usage
```
/voice-setup - configuration vocale
/voice-debug - debug reconnaissance vocale
/ai-optimize - optimisation IA
/voice-permissions - gestion permissions audio
```
